## Descripción

La guía reúne conocimientos por áreas y busca construir una base sólida que permita comprender diferentes tecnologías y aplicarlas de forma transversal.

> [!IMPORTANT]
> La guía busca desarrollar **conocimientos transversales**, no únicamente aprender tecnologías concretas. La intención es comprender los fundamentos, principios y relaciones que se mantienen entre diferentes herramientas y stacks, de forma que estos conocimientos puedan aplicarse independientemente de la tecnología utilizada.
>
> Esta perspectiva cobra especial importancia con la evolución de la **IA y las nuevas formas de desarrollar software**. El objetivo no es memorizar código ni depender de una herramienta concreta, sino disponer de los conocimientos necesarios para entender los problemas, tomar decisiones, diseñar soluciones, revisar y validar el código generado y utilizar la IA como una herramienta para aumentar la productividad.

Esta sección reúne los conocimientos teóricos y los principios fundamentales del desarrollo de software, organizados por áreas de conocimiento.
