## Tipos de Condicionales

Existen diferentes tipos de condicionales en inglés que se usan dependiendo del contexto (si la situación es real, posible, o completamente irreal). La estructura y el uso de los tiempos verbales varía de acuerdo con el tipo de condicional:

| **Tipo de Condicional** | **Uso**                                | **Estructura**                                               | **Ejemplo**                                            |
| ----------------------- | -------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------ |
| **Condicional Tipo 0**  | Hechos generales, verdades universales | If + presente simple → presente simple                       | If you heat water to 100°C, it boils.                  |
| **Condicional Tipo 1**  | Situaciones posibles en el futuro      | If + presente simple → futuro simple (will)                  | If you study, you will pass the exam.                  |
| **Condicional Tipo 2**  | Situaciones hipotéticas en el presente | If + pasado simple → condicional simple (would + verbo)      | If I had more time, I would travel more.               |
| **Condicional Tipo 3**  | Situaciones hipotéticas en el pasado   | If + pasado perfecto → condicional perfecto (would have + p) | If I had studied harder, I would have passed the exam. |

## Condicional Tipo 0 (Zero Conditional)

El Condicional Tipo 0 se utiliza para expresar hechos generales o verdades universales que siempre son verdaderas, sin importar la situación.

> If + presente simple → presente simple

Ejemplo:

- If you heat water to 100°C, it boils.
- (Si calientas agua a 100°C, hierve).

Uso: Se usa para hechos científicos, reglas o verdades universales.

## Condicional Tipo 1 (First Conditional)

El Condicional Tipo 1 se utiliza para hablar de situaciones reales o posibles en el futuro. Describe lo que es probable que suceda si se cumple una condición.

> If + presente simple → futuro simple (will)

Ejemplo:

- If you study, you will pass the exam.
- (Si estudias, aprobarás el examen).

Uso: Para describir acciones futuras que son probables bajo ciertas condiciones.

## Condicional Tipo 2 (Second Conditional)

El Condicional Tipo 2 se utiliza para hablar de situaciones hipotéticas o improbables en el presente o el futuro. Describe lo que podría suceder si una condición improbable o irreal se cumpliera.

> If + pasado simple → condicional simple (would + verbo base)

Ejemplo:

- If I had more time, I would travel more.
- (Si tuviera más tiempo, viajaría más).

Uso: Para describir situaciones imaginarias o improbables.

## Condicional Tipo 3 (Third Conditional)

El Condicional Tipo 3 se usa para hablar de situaciones hipotéticas en el pasado que no sucedieron. Describe lo que podría haber pasado si una condición en el pasado hubiera sido diferente.

> If + pasado perfecto → condicional perfecto (would have + participio)

Ejemplo:

- If I had studied harder, I would have passed the exam.
- (Si hubiera estudiado más, habría aprobado el examen).

Uso: Para expresar arrepentimientos o situaciones hipotéticas en el pasado.
