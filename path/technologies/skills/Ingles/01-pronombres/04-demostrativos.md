## Pronombres Demostrativos

Los pronombres demostrativos se usan para señalar o referirse a personas, objetos o cosas específicas en relación con la distancia (cercana o lejana) y el número (singular o plural).

## Lista de pronombres demostrativos

| Pronombre | Traducción                        | Uso               | Ejemplo                                           |
| --------- | --------------------------------- | ----------------- | ------------------------------------------------- |
| **This**  | Esto / Este / Esta                | Singular, cercano | **This** is my book. (Este es mi libro.)          |
| **That**  | Eso / Ese / Esa / Aquel / Aquella | Singular, lejano  | **That** is your car. (Ese es tu coche.)          |
| **These** | Estos / Estas                     | Plural, cercano   | **These** are my shoes. (Estos son mis zapatos.)  |
| **Those** | Esos / Esas / Aquellos / Aquellas | Plural, lejano    | **Those** are her friends. (Esos son sus amigos.) |

## Uso de los pronombres demostrativos

### Cercanía (This/These)

Se usan para señalar algo o alguien que está cerca del hablante.

- This (singular): This is my pen. (Esta es mi pluma.)
- These (plural): These are apples. (Estas son manzanas.)

### Lejanía (That/Those)

Se usan para referirse a algo o alguien que está lejos del hablante.

- That (singular): That is a plane. (Ese es un avión.)
- Those (plural): Those are birds. (Esos son pájaros.)

### Como pronombres (sin sustantivo)

Actúan solos y reemplazan a un sustantivo.

- Ejemplo: I like this. (Me gusta esto.)

### Como adjetivos demostrativos (antes de un sustantivo):

Modifican un sustantivo en lugar de reemplazarlo.

- Ejemplo: This book is mine. (Este libro es mío.)

## Notas importantes

### Con sustantivos incontables:

Los pronombres demostrativos también se pueden usar con cosas que no se pueden contar.

- Ejemplo: This is water. (Esto es agua.)

### Diferencias de singular y plural:

- Singular: This (cerca) y That (lejos).
- Plural: These (cerca) y Those (lejos).
