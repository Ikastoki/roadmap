## Pronombres Personales

Los pronombres personales son palabras que se utilizan para sustituir a los sustantivos (generalmente personas) en una oración, evitando la repetición de nombres. Se emplean para hacer referencia a las personas que participan en la acción verbal: quien habla (primera persona), quien escucha (segunda persona) y de quien se habla (tercera persona).

## Lista de pronombres posesivos

| Pronombre  | Traducción           | Ejemplo                                            |
| ---------- | -------------------- | -------------------------------------------------- |
| **Mine**   | Mío/a                | This book is **mine**. (Este libro es mío.)        |
| **Yours**  | Tuyo/a               | Is this pen **yours**? (¿Es esta pluma tuya?)      |
| **His**    | Suyo/a (de él)       | That car is **his**. (Ese coche es suyo.)          |
| **Hers**   | Suyo/a (de ella)     | The bag is **hers**. (La bolsa es suya.)           |
| **Its**    | Suyo/a (de eso)      | The tail is **its**. (La cola es suya.)            |
| **Ours**   | Nuestro/a            | The house is **ours**. (La casa es nuestra.)       |
| **Yours**  | Suyo/a (de ustedes)  | The idea was **yours**. (La idea era suya.)        |
| **Theirs** | Suyo/a (de ellos/as) | The toys are **theirs**. (Los juguetes son suyos.) |

## Notas

Diferencia entre adjetivos posesivos y pronombres posesivos:

- Los adjetivos posesivos (my, your, his, her, its, our, their) siempre acompañan a un sustantivo.
  - Ejemplo: This is my book. (Este es mi libro.)
- Los pronombres posesivos reemplazan al sustantivo.
  - Ejemplo: This book is mine. (Este libro es mío.)
