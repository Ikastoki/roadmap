## Comparación con "as... as”

La estructura "as... as" se utiliza en inglés para hacer comparaciones de igualdad. Indica que dos cosas, personas o situaciones son iguales o similares en alguna característica o cualidad. Es una forma común y útil de comparar cuando no se quiere expresar superioridad o inferioridad, sino equivalencia.

| **Comparación**             | **Ejemplo**                                           |
| --------------------------- | ----------------------------------------------------- |
| **Positiva (igualdad)**     | **She is as smart as her sister.**                    |
|                             | (Ella es tan inteligente como su hermana.)            |
| **Negativa (desigualdad)**  | **He is not as strong as his brother.**               |
|                             | (Él no es tan fuerte como su hermano.)                |
| **Sustantivos (much/many)** | **I don't have as many books as you.**                |
|                             | (No tengo tantos libros como tú.)                     |
| **Adverbios**               | **She speaks as fluently as a native speaker.**       |
|                             | (Ella habla tan fluidamente como un hablante nativo.) |

## Comparación de Igualdad (Positiva)

Cuando queremos decir que dos cosas o personas son iguales o tienen la misma cantidad de una cualidad, usamos la estructura:

> as + adjetivo/adverbio + as

- She is as tall as her brother.
  - (Ella es tan alta como su hermano.)
- This cake is as delicious as the one you made last week.
  - (Este pastel es tan delicioso como el que hiciste la semana pasada.)
- He runs as fast as a professional athlete.
  - (Él corre tan rápido como un atleta profesional.)

## Comparación de Desigualdad (Negativa)

Cuando queremos decir que una cosa o persona no es tan igual o tan similar como otra en alguna característica, usamos la forma negativa de la estructura:

> not as + adjetivo/adverbio + as

- This car is not as expensive as I thought.
  - (Este coche no es tan caro como pensé.)
- My house is not as big as yours.
  - (Mi casa no es tan grande como la tuya.)
- The movie wasn't as interesting as the book.
  - (La película no fue tan interesante como el libro.)

## Uso de Sustantivos con "as... as"

En algunos casos, puedes comparar cantidades o niveles utilizando un sustantivo en lugar de un adjetivo o adverbio. Para hacerlo, se añade la palabra much o many entre los "as... as".

> as much/many + sustantivo + as

- She doesn't have as much money as her sister.
  - (Ella no tiene tanto dinero como su hermana.)
- We received as many invitations as we expected.
  - (Recibimos tantas invitaciones como esperábamos.)

Recuerda que se usa `much` con sustantivos incontables y `many` con sustantivos contables.

## Comparación con Adverbios

También se puede usar "as... as" con adverbios para comparar cómo se realiza una acción.

- He sings as beautifully as a professional singer.
  - (Él canta tan hermosamente como un cantante profesional.)
- You don’t dance as gracefully as your sister.
  - (No bailas tan graciosamente como tu hermana.)

## Expresiones Comunes con "as... as"

En inglés existen muchas expresiones fijas con "as... as" que se usan para enfatizar comparaciones. Aquí algunos ejemplos:

- As cold as ice → Tan frío como el hielo.
- As busy as a bee → Tan ocupado como una abeja.
- As easy as pie → Tan fácil como un pastel (significa que algo es muy fácil).
- As blind as a bat → Tan ciego como un murciélago (significa que alguien no ve bien).

Estas expresiones suelen ser figurativas y muy comunes en el habla cotidiana.
