## Artículos y sustantivos incontables

Los sustantivos incontables son aquellos que no se pueden contar individualmente, ya que generalmente representan sustancias, ideas o conceptos abstractos. No tienen forma plural y no se pueden usar con números directamente (por ejemplo, no se puede decir "one water" o "two informations").

Los sustantivos incontables no llevan artículo indefinido ("a" o "an"), pero en algunos casos pueden llevar el artículo definido "the" cuando nos referimos a algo específico.

## Ejemplos de sustantivos incontables comunes

| Categoría               | Ejemplos                                        |
| ----------------------- | ----------------------------------------------- |
| Sustancias y materiales | Water, air, milk, oil, salt, sugar              |
| Conceptos abstractos    | Love, information, advice, knowledge, happiness |
| Actividades             | Work, homework, travel, research                |
| Otros                   | Money, furniture, luggage, equipment            |

## Reglas para usar artículos con sustantivos incontables

### No se usa "a" o "an" con sustantivos incontables

El artículo indefinido "a" o "an" se usa solo con sustantivos contables en singular. No se puede usar con sustantivos incontables porque no se pueden contar individualmente.

| Ejemplo incorrecto       | Ejemplo correcto      | Traducción              |
| ------------------------ | --------------------- | ----------------------- |
| I need _a_ water.        | I need Ø water.       | Necesito agua.          |
| She gave me _an_ advice. | She gave me Ø advice. | Ella me dio un consejo. |

### Se usa "the" con sustantivos incontables cuando son específicos

Cuando nos referimos a algo incontable de manera específica o particular, se puede usar el artículo definido "the".

| Ejemplo en inglés                       | Traducción en español                 |
| --------------------------------------- | ------------------------------------- |
| The information you gave me was useful. | La información que me diste fue útil. |
| The water in this bottle is cold.       | El agua de esta botella está fría.    |
| I need the money that you owe me.       | Necesito el dinero que me debes.      |

### No se usa artículo cuando hablamos de sustantivos incontables en general

Si hablamos de una sustancia o concepto de forma general, no usamos artículo alguno.

| Ejemplo en inglés              | Traducción en español               |
| ------------------------------ | ----------------------------------- |
| Ø Knowledge is power.          | El conocimiento es poder.           |
| Ø Sugar is bad for your teeth. | El azúcar es malo para los dientes. |
| Ø Love is important in life.   | El amor es importante en la vida.   |

## Cómo cuantificar los sustantivos incontables

Para cuantificar los sustantivos incontables, se usan expresiones como "a piece of", "a bottle of", "some", "a lot of", entre otras. Estas expresiones permiten hablar de cantidades específicas de algo incontable.

| Ejemplo en inglés                           | Traducción en español                              |
| ------------------------------------------- | -------------------------------------------------- |
| I need a bottle of water.                   | Necesito una botella de agua.                      |
| She gave me a piece of advice.              | Ella me dio un consejo.                            |
| We need some information about the project. | Necesitamos algo de información sobre el proyecto. |
| He has a lot of money.                      | Él tiene mucho dinero.                             |

## Ejemplos de uso de sustantivos incontables con artículos

| Ejemplo en inglés                       | Traducción en español                               |
| --------------------------------------- | --------------------------------------------------- |
| Can you give me Ø advice?               | ¿Me puedes dar un consejo?                          |
| Ø Money doesn't buy Ø happiness.        | El dinero no compra la felicidad.                   |
| The water in the lake is very clean.    | El agua del lago está muy limpia.                   |
| She is doing Ø research for her thesis. | Ella está haciendo una investigación para su tesis. |

## Notas

- No se usa "a" o "an" con sustantivos incontables.
- Se puede usar "the" si nos referimos a algo específico (por ejemplo, "the money in my wallet").
- Cuando hablamos de sustantivos incontables de manera general, no se usa ningún artículo (por ejemplo, "Ø Water is essential for life").
- Para expresar cantidades específicas de algo incontable, se usan expresiones como "a piece of", "some", "a lot of"
