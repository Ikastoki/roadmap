## El infinitivo y el gerundio

En inglés, el uso de infinitivos y gerundios es clave para formar estructuras verbales, expresar acciones y completar significados en oraciones. Aunque ambos se refieren a acciones, su uso varía dependiendo de la situación o verbo que los acompañe.

| **Forma**                  | **Uso Común**                                                 | **Ejemplo**                                          |
| -------------------------- | ------------------------------------------------------------- | ---------------------------------------------------- |
| **Infinitivo**             | Después de ciertos verbos, adjetivos y para propósito         | She **decided to go** home.                          |
| **Gerundio**               | Como sujeto, después de preposiciones y ciertos verbos        | **Swimming** is fun. / I enjoy **reading**.          |
| **Ambos**                  | Algunos verbos permiten ambos sin diferencia                  | I **like swimming**. / I **like to swim**.           |
| **Cambian de significado** | Algunos verbos cambian de significado según se use uno u otro | She **stopped smoking**. / She **stopped to smoke**. |

## El Infinitivo

El infinitivo en inglés se forma con la partícula "to" seguida del verbo base (sin conjugar).

Estructura:

> to + verbo base

Ejemplo: to eat, to run, to study

### Después de ciertos verbos

Algunos verbos requieren el uso del infinitivo para completar su significado.

| **Verbo** | **Ejemplo con Infinitivo**          |
| --------- | ----------------------------------- |
| agree     | They **agreed to help** us.         |
| decide    | She **decided to go** to the party. |
| hope      | I **hope to travel** next year.     |
| need      | We **need to buy** groceries.       |
| plan      | They **plan to visit** Europe.      |
| want      | I **want to learn** English.        |

### Después de adjetivos

El infinitivo también se utiliza después de ciertos adjetivos.

| **Adjetivo** | **Ejemplo con Infinitivo**                   |
| ------------ | -------------------------------------------- |
| happy        | I'm **happy to see** you.                    |
| difficult    | This problem is **difficult to solve**.      |
| ready        | She’s **ready to start**.                    |
| surprised    | We were **surprised to find** out the truth. |

### Para expresar propósito o intención

El infinitivo puede expresar la finalidad de una acción.

Ejemplo:

- I went to the store to buy some food.
- (Fui a la tienda para comprar algo de comida.)

## El Gerundio

El gerundio en inglés se forma añadiendo "-ing" al verbo base. Funciona como un sustantivo y se usa para referirse a acciones como conceptos generales.

Estructura:

> verbo base + -ing

Ejemplo: eating, running, studying

### Como sujeto de la oración

El gerundio puede actuar como el sujeto de una oración.

| **Ejemplo**                       |
| --------------------------------- |
| **Swimming** is good exercise.    |
| **Reading** is my favorite hobby. |
| **Learning** English takes time.  |

### Después de preposiciones

El gerundio se usa después de preposiciones.

| **Preposición + Gerundio**                     |
| ---------------------------------------------- |
| I'm interested in **learning** more.           |
| They left without **saying** goodbye.          |
| We're thinking about **moving** to a new city. |

### Después de ciertos verbos

Algunos verbos requieren el uso del gerundio.

| **Verbo** | **Ejemplo con Gerundio**                  |
| --------- | ----------------------------------------- |
| enjoy     | She **enjoys reading** books.             |
| avoid     | He **avoids eating** junk food.           |
| consider  | They are **considering moving** to Spain. |
| suggest   | I **suggest going** to the park.          |
| finish    | We **finished studying** for the test.    |

## Diferencias Clave entre Infinitivo y Gerundio

Aunque el infinitivo y el gerundio se usan para expresar acciones, algunos verbos permiten el uso de ambos con ligeras diferencias en significado, mientras que otros solo aceptan una de las dos formas.

### Verbos que permiten infinitivo o gerundio (sin cambiar el significado)

Algunos verbos pueden ir seguidos de infinitivo o gerundio sin una gran diferencia en el significado.

| **Verbo** | **Ejemplo con Gerundio**      | **Ejemplo con Infinitivo**    |
| --------- | ----------------------------- | ----------------------------- |
| like      | I **like swimming**.          | I **like to swim**.           |
| love      | They **love dancing**.        | They **love to dance**.       |
| start     | We **started working** early. | We **started to work** early. |

### Verbos que cambian de significado según se use el infinitivo o gerundio

Algunos verbos cambian de significado según se utilice el gerundio o el infinitivo.

| **Verbo** | **Con Gerundio**                                                     | **Con Infinitivo**                                          |
| --------- | -------------------------------------------------------------------- | ----------------------------------------------------------- |
| remember  | I **remember locking** the door. (Recuerdo haber cerrado la puerta.) | **Remember to lock** the door. (Recuerda cerrar la puerta.) |
| stop      | She **stopped smoking**. (Dejó de fumar.)                            | She **stopped to smoke**. (Se detuvo para fumar.)           |
| try       | I **tried calling** him. (Intenté llamarlo, pero no contestó.)       | **Try to call** him later. (Intenta llamarlo más tarde.)    |
