## Verbos regulares e irregulares

En inglés, los verbos se clasifican en regulares e irregulares dependiendo de cómo forman su pasado simple y participio pasado. Esta clasificación es fundamental para conjugar correctamente los verbos en distintos tiempos verbales.

Los verbos regulares siguen una regla fija para formar el pasado simple y el participio pasado: añaden la terminación "-ed" o "-d" al final del verbo.

## Reglas para formar el pasado simple y el participio pasado de los verbos regulares

| **Verbo en Infinitivo** | **Pasado Simple** | **Participio Pasado** |
| ----------------------- | ----------------- | --------------------- |
| work                    | worked            | worked                |
| talk                    | talked            | talked                |
| clean                   | cleaned           | cleaned               |
| cook                    | cooked            | cooked                |
| jump                    | jumped            | jumped                |
| call                    | called            | called                |
| want                    | wanted            | wanted                |
| play                    | played            | played                |

### Verbos que terminan en consonante

Se añade "-ed".

Ejemplos:

- play → played
- watch → watched

### Verbos que terminan en "e"

Se añade solo "-d".

Ejemplos:

- love → loved
- like → liked

### Verbos que terminan en consonante + "y"

Se cambia la "y" por "-ied".

Ejemplos:

- study → studied
- carry → carried

### Verbos que terminan en una vocal + "y"

Solo se añade "-ed".

Ejemplos:

- play → played
- enjoy → enjoyed

### Verbos de una sílaba que terminan en consonante-vocal-consonante (CVC)

Se duplica la última consonante antes de añadir "-ed".

Ejemplos:

- stop → stopped
- plan → planned

## Verbos Irregulares

Los verbos irregulares no siguen una regla fija para formar el pasado simple ni el participio pasado. Cada verbo irregular tiene una forma única para estos tiempos, por lo que es necesario memorizar sus conjugaciones.

| **Verbo en Infinitivo** | **Pasado Simple** | **Participio Pasado** |
| ----------------------- | ----------------- | --------------------- |
| be                      | was/were          | been                  |
| begin                   | began             | begun                 |
| break                   | broke             | broken                |
| choose                  | chose             | chosen                |
| drink                   | drank             | drunk                 |
| eat                     | ate               | eaten                 |
| fly                     | flew              | flown                 |
| give                    | gave              | given                 |
| know                    | knew              | known                 |
| run                     | ran               | run                   |
| speak                   | spoke             | spoken                |
| swim                    | swam              | swum                  |
| write                   | wrote             | written               |

### Verbos que no cambian (idénticos en presente, pasado simple y participio pasado)

Ejemplos:

- cut → cut → cut
- put → put → put

### Verbos que cambian su forma en el pasado simple y participio pasado

Ejemplos:

- go → went → gone
- see → saw → seen
- take → took → taken

### Verbos cuyo pasado simple y participio pasado son iguales, pero diferentes del infinitivo

Ejemplos:

- buy → bought → bought
- feel → felt → felt
- bring → brought → brought

## Diferencias Clave entre Verbos Regulares e Irregulares

| **Aspecto**            | **Verbos Regulares**              | **Verbos Irregulares**                                   |
| ---------------------- | --------------------------------- | -------------------------------------------------------- |
| **Regla de formación** | Se añade **"-ed"** o **"-d"**     | No siguen una regla; se memorizan individualmente        |
| **Consistencia**       | La forma del pasado es predecible | La forma del pasado puede cambiar de manera impredecible |
| **Ejemplo**            | work → worked → worked            | go → went → gone                                         |
