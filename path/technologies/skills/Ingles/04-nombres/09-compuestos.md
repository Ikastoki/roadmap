## Nombres compuestos

Los nombres compuestos en inglés son aquellos formados por la combinación de dos o más palabras que juntas crean un nuevo significado. Estas palabras pueden ser una combinación de sustantivos, adjetivos, verbos o preposiciones que, al unirse, forman un nombre con un significado diferente al de las palabras por separado.

Los nombres compuestos pueden escribirse de tres maneras diferentes

- Separados (como palabras independientes)
- Unidos (como una sola palabra)
- Con guión (unidos por un guión)

### Tipos de Nombres Compuestos

Nombres compuestos separados: Estas palabras están escritas como dos palabras separadas pero funcionan como una sola unidad.

Ejemplos:

- Bus stop (parada de autobús)
- High school (escuela secundaria)
- Fire station (estación de bomberos)

### Nombres compuestos unidos: Estas palabras se escriben juntas como una sola palabra.

Ejemplos:

- Toothpaste (pasta de dientes)
- Bedroom (dormitorio)
- Notebook (cuaderno)

### Nombres compuestos con guión: Estas palabras están unidas por un guión y forman una sola unidad de significado.

Ejemplos:

- Mother-in-law (suegra)
- Check-in (registro, facturación)
- Father-in-law (suegro)

## Formación de los Nombres Compuestos

Los nombres compuestos pueden formarse mediante la combinación de diferentes tipos de palabras.

### Sustantivo + Sustantivo

- Football (fútbol)
- Bookshelf (estantería)

### Adjetivo + Sustantivo

- Greenhouse (invernadero)
- Full moon (luna llena)

### Verbo + Sustantivo

- Swimming pool (piscina)
- Washing machine (lavadora)

### Sustantivo + Verbo

- Rainfall (precipitación, lluvia)
- Sunrise (amanecer)

### Verbo + Preposición

- Breakdown (avería, colapso)
- Takeoff (despegue)

### Preposición + Sustantivo

- Underground (subterráneo, metro)
- Overcoat (sobretodo, abrigo)

### Preposición + Verbo

- Output (producción)
- Input (entrada)

## Pluralización de los Nombres Compuestos

La forma de pluralizar los nombres compuestos depende de la estructura de cada compuesto:

Cuando el primer elemento es el sustantivo principal, se pluraliza el primer sustantivo.

- Toothbrush → Toothbrushes (cepillos de dientes)
- Son-in-law → Sons-in-law (yernos)

Cuando el segundo elemento es el sustantivo principal, se pluraliza el segundo sustantivo.

- Bedroom → Bedrooms (dormitorios)
- Schoolteacher → Schoolteachers (profesores de escuela)

Nombres compuestos escritos como una sola palabra suelen pluralizarse al final.

- Notebook → Notebooks (cuadernos)
- Handbag → Handbags (bolsos)
