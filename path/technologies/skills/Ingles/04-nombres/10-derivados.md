## Nombres Derivados

Los nombres derivados en inglés son sustantivos que se forman a partir de otras palabras, como verbos, adjetivos o incluso otros sustantivos, al agregar prefijos o sufijos. Este proceso se llama derivación. Los sufijos son las terminaciones añadidas al final de una palabra para crear un nuevo sustantivo.

## Formación de Nombres Derivados

Los nombres derivados se crean principalmente añadiendo sufijos a verbos, adjetivos u otras formas de palabras. Aquí te explico cómo funciona la derivación con los sufijos más comunes en inglés.

### Nombres derivados de Verbos

Los verbos pueden transformarse en sustantivos agregando sufijos como -ment, -tion, -sion, -ance, -ence, y -al.

#### -ment

Se añade a algunos verbos para formar nombres que indican acciones o estados.

**Ejemplos:**

- Develop → Development (desarrollo)
- Enjoy → Enjoyment (disfrute)

#### -tion / -sion

Estos sufijos forman nombres que generalmente denotan acciones, procesos o estados.

**Ejemplos:**

- Inform → Information (información)
- Decide → Decision (decisión)

#### -ance / -ence

Se usan para formar sustantivos abstractos que indican estados, acciones o cualidades.

**Ejemplos:**

- Perform → Performance (actuación, desempeño)
- Exist → Existence (existencia)

#### -al

Este sufijo forma nombres que también indican acciones o procesos.

**Ejemplos:**

- Approve → Approval (aprobación)
- Arrive → Arrival (llegada)

### Nombres derivados de Adjetivos

Los adjetivos pueden convertirse en sustantivos añadiendo sufijos como -ness, -ity, -dom, y -cy.

#### -ness

Se utiliza para formar nombres que expresan estados o cualidades.

**Ejemplos:**

- Happy → Happiness (felicidad)
- Kind → Kindness (amabilidad)

#### -ity

Forma nombres que indican estados o condiciones.

**Ejemplos:**

- Real → Reality (realidad)
- Able → Ability (habilidad)

#### -dom

Se usa para formar nombres que indican un estado o dominio.

**Ejemplos:**

- Free → Freedom (libertad)
- King → Kingdom (reino)

#### -cy

Sufijo que forma nombres abstractos de estados o cualidades.

**Ejemplos:**

- Private → Privacy (privacidad)
- Efficient → Efficiency (eficiencia)

### Nombres derivados de Otros Nombres

Algunos nombres también pueden derivarse de otros sustantivos, especialmente usando sufijos como -hood, -ship, y -ism.

#### -hood

Forma nombres que denotan estados, condiciones o relaciones.

**Ejemplos:**

- Child → Childhood (infancia)
- Brother → Brotherhood (hermandad)

#### -ship

Este sufijo indica posición, condición o habilidad.

**Ejemplos:**

- Friend → Friendship (amistad)
- Leader → Leadership (liderazgo)

#### -ism

Se utiliza para formar nombres abstractos que describen sistemas de creencias o doctrinas.

**Ejemplos:**

- Capital → Capitalism (capitalismo)
- Real → Realism (realismo)

### Nombres derivados de Prefijos

Además de los sufijos, algunos nombres se forman agregando prefijos a otras palabras. Los prefijos cambian el significado del nombre original, dándole un nuevo matiz o indicando negación, tamaño o cantidad.

#### Un-

Indica negación o el contrario.

**Ejemplo:**

- Known → Unknown (desconocido)

###### Mis-

Indica un error o algo incorrecto.

**Ejemplo:**

- Take → Mistake (error)

#### Over-

Indica exceso o algo que está por encima.

**Ejemplo:**

- Load → Overload (sobrecarga)

#### Under-

Indica insuficiencia o algo que está por debajo.

**Ejemplo:**

- Graduate → Undergraduate (estudiante de licenciatura)
