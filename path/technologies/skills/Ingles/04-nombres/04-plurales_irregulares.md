## Plurales Irregulares

Algunos sustantivos en inglés tienen plurales irregulares, lo que significa que no siguen las reglas generales para la formación del plural. Estos sustantivos cambian por completo en su forma plural.

| Singular | Plural   |
| -------- | -------- |
| man      | men      |
| woman    | women    |
| child    | children |
| tooth    | teeth    |
| foot     | feet     |
| mouse    | mice     |
| goose    | geese    |
| person   | people   |

The children are playing in the park. (Los niños están jugando en el parque.)

I saw two mice in the kitchen. (Vi dos ratones en la cocina.)

## Nombres que no cambian en plural

Algunos sustantivos en inglés tienen la misma forma en singular y en plural.

| Singular | Plural   |
| -------- | -------- |
| sheep    | sheep    |
| deer     | deer     |
| fish     | fish     |
| aircraft | aircraft |

We saw five sheep in the field. (Vimos cinco ovejas en el campo.)

He caught three fish yesterday. (Él atrapó tres peces ayer.)

## Sustantivos que siempre son plurales

Algunos sustantivos en inglés solo se usan en plural, aunque se refieran a un solo objeto o par de objetos.

| Singular | Plural   |
| -------- | -------- |
| scissors | scissors |
| trousers | trousers |
| glasses  | glasses  |
| jeans    | jeans    |
| pyjamas  | pyjamas  |

I need new glasses. (Necesito nuevas gafas.)

These jeans are too tight. (Estos jeans están muy ajustados.)
