## Nombres contables e incontables

En inglés, los sustantivos (nombres) se dividen en dos categorías principales según su capacidad de ser contados: nombres contables (countable nouns) e incontables (uncountable nouns). Esta distinción es importante porque afecta cómo usamos artículos, números y ciertas palabras de cantidad. A continuación, te explico ambos tipos con ejemplos y detalles.

## Nombres Contables (Countable Nouns)

Los nombres contables son aquellos que se pueden contar individualmente. Tienen forma singular y plural, y es posible usarlos con números o con palabras como "a" o "an".

### Características

- Tienen una forma singular y plural.
- Se pueden contar (1, 2, 3, etc.).
- Se pueden usar con números y artículos indefinidos (a/an).

### Ejemplos de Nombres Contables

| Singular | Plural | Ejemplo en una oración en inglés              | Traducción al español                                   |
| -------- | ------ | --------------------------------------------- | ------------------------------------------------------- |
| apple    | apples | She ate **an apple**.                         | Ella se comió **una manzana**.                          |
| car      | cars   | There are two **cars** in the garage.         | Hay dos **coches** en el garaje.                        |
| book     | books  | I bought **a book** yesterday.                | Compré **un libro** ayer.                               |
| chair    | chairs | We need four **chairs** for the dining table. | Necesitamos cuatro **sillas** para la mesa del comedor. |
| dog      | dogs   | He has three **dogs**.                        | Él tiene tres **perros**.                               |

### Uso de Artículos con Nombres Contables:

- Singular: Usamos "a" o "an" para referirnos a una sola cosa (an apple, a car).
- Plural: Usamos la forma plural y no es necesario usar un artículo (apples, cars).

## Nombres Incontables (Uncountable Nouns)

Los nombres incontables son aquellos que no se pueden contar individualmente porque representan sustancias, conceptos o materiales que no tienen una cantidad definida. No tienen forma plural y no se usan con números directos.

### Características:

No tienen forma plural.
No se pueden contar directamente con números.
Se usan con palabras de cantidad como some, much, a lot of y a little.
No se usan con artículos indefinidos (a/an).

### Ejemplos de Nombres Incontables

| Nombres incontables | Ejemplo en una oración en inglés             | Traducción al español                             |
| ------------------- | -------------------------------------------- | ------------------------------------------------- |
| water               | There is **some water** in the glass.        | Hay **algo de agua** en el vaso.                  |
| money               | She doesn’t have **much money**.             | Ella no tiene **mucho dinero**.                   |
| advice              | He gave me **good advice**.                  | Él me dio **buenos consejos**.                    |
| information         | I need **some information** about the event. | Necesito **algo de información** sobre el evento. |
| furniture           | They bought **new furniture** for the house. | Compraron **muebles nuevos** para la casa.        |
| music               | She loves listening to **music**.            | Le encanta escuchar **música**.                   |
| rice                | We need **a little rice** for the recipe.    | Necesitamos **un poco de arroz** para la receta.  |
| air                 | The **air** is fresh today.                  | El **aire** está fresco hoy.                      |

### Uso de Artículos y Cantidades con Nombres Incontables

- No se usan los artículos "a" o "an" con nombres incontables.
- Usamos palabras de cantidad como some, much, a lot of, a little para referirnos a cantidades de nombres incontables.

## Comparación entre Nombres Contables e Incontables

| Característica        | Nombres Contables                    | Nombres Incontables                        |
| --------------------- | ------------------------------------ | ------------------------------------------ |
| Forma plural          | Sí, tienen plural (books, apples)    | No tienen plural (advice, money)           |
| Se pueden contar      | Sí (one apple, two apples)           | No (no se puede decir "two waters")        |
| Artículos indefinidos | Usan "a" o "an" en singular (a dog)  | No usan "a" o "an" (water, information)    |
| Palabras de cantidad  | Many, a few (many cars, a few books) | Much, a little (much money, a little rice) |

## Notas

- Nombres contables: Tienen plural, se pueden contar y usan artículos indefinidos.
- Nombres incontables: No tienen plural, no se pueden contar y no usan artículos indefinidos. Usan palabras como some, much, a lot of, y a little para indicar cantidad.
- Es importante reconocer qué nombres son contables e incontables porque esto afecta cómo se construyen las oraciones en inglés.
