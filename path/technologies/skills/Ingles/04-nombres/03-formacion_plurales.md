## Formación del plural

La formación del plural de los sustantivos sigue varias reglas, tanto generales como especiales. Además, hay nombres que tienen plurales irregulares.

## Reglas Generales para la Formación del Plural

### Regla 1: Añadir "-s" al final del sustantivo

La mayoría de los sustantivos en inglés forman el plural simplemente añadiendo una -s al final de la palabra.

| Singular | Plural |
| -------- | ------ |
| car      | cars   |
| dog      | dogs   |
| book     | books  |
| apple    | apples |
| chair    | chairs |

I have two cars. (Tengo dos coches.)

There are many books on the shelf. (Hay muchos libros en el estante.)

## Reglas Especiales para la Formación del Plural

### Regla 2: Sustantivos que terminan en "-s", "-ss", "-sh", "-ch", "-x" o "-z"

Para estos sustantivos, se añade -es al final para formar el plural, ya que la pronunciación de la simple -s sería difícil.

| Singular | Plural  |
| -------- | ------- |
| bus      | buses   |
| kiss     | kisses  |
| brush    | brushes |
| box      | boxes   |
| watch    | watches |

There are three buses on the street. (Hay tres autobuses en la calle.)

She has two watches. (Ella tiene dos relojes.)

### Regla 3: Sustantivos que terminan en consonante + "y"

Si el sustantivo termina en una consonante seguida de -y, se cambia la -y por -ies para formar el plural

| Singular | Plural    |
| -------- | --------- |
| baby     | babies    |
| city     | cities    |
| party    | parties   |
| lady     | ladies    |
| country  | countries |

The babies are sleeping. (Los bebés están durmiendo.)

They visited several cities in Europe. (Visitaron varias ciudades en Europa.)

### Regla 4: Sustantivos que terminan en vocal + "y"

Si el sustantivo termina en una vocal seguida de -y, simplemente se añade -s para formar el plural.

| Singular | Plural  |
| -------- | ------- |
| boy      | boys    |
| toy      | toys    |
| day      | days    |
| key      | keys    |
| monkey   | monkeys |

The boys are playing soccer. (Los chicos están jugando fútbol.)

She has many keys on her keychain. (Ella tiene muchas llaves en su llavero.)

### Regla 5: Sustantivos que terminan en "-f" o "-fe"

Para algunos sustantivos que terminan en -f o -fe, el f cambia a v y se añade -es para formar el plural. Sin embargo, no todos los sustantivos que terminan en -f siguen esta regla.

| Singular | Plural  |
| -------- | ------- |
| knife    | knives  |
| leaf     | leaves  |
| wife     | wives   |
| life     | lives   |
| shelf    | shelves |

The chef has several knives. (El chef tiene varios cuchillos.)

The trees are losing their leaves. (Los árboles están perdiendo sus hojas.)

#### Excepciones

Algunos sustantivos que terminan en -f o -fe solo añaden -s para formar el plural.

| Singular | Plural  |
| -------- | ------- |
| roof     | roofs   |
| belief   | beliefs |
| chief    | chiefs  |
| cliff    | cliffs  |

### Regla 6: Sustantivos que terminan en "-o"

Algunos sustantivos que terminan en -o añaden -es para formar el plural, especialmente si se refieren a cosas o palabras de origen italiano o español, mientras que otros solo añaden -s.

| Singular | Plural   |
| -------- | -------- |
| tomato   | tomatoes |
| potato   | potatoes |
| hero     | heroes   |
| echo     | echoes   |

Sin embargo, muchos otros sustantivos que terminan en -o solo añaden -s:

| Singular | Plural |
| -------- | ------ |
| photo    | photos |
| piano    | pianos |
| video    | videos |
| radio    | radios |
