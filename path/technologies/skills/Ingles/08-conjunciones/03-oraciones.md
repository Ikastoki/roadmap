## Conjunciones en oraciones condicionales

Las oraciones condicionales son aquellas que expresan una condición y el resultado o consecuencia que ocurrirá si esa condición se cumple. Estas oraciones constan de dos partes:

- La cláusula condicional (también llamada "si clause"): Expresa la condición.
- La cláusula principal: Expresa el resultado o consecuencia de esa condición.

Las oraciones condicionales suelen introducirse con conjunciones específicas que establecen la relación entre la condición y el resultado.

| **Conjunción**      | **Uso**                              | **Ejemplo**                                                 |
| ------------------- | ------------------------------------ | ----------------------------------------------------------- |
| **If**              | Condición general                    | If it rains, we will stay home.                             |
| **Unless**          | Condición negativa                   | We won’t go unless you come with us.                        |
| **Provided (that)** | Condición con requisitos específicos | You can go out provided that you finish your homework.      |
| **As long as**      | Condición con límite o duración      | You can stay here as long as you don’t make any noise.      |
| **In case**         | Precaución o medida preventiva       | Take a coat in case it gets cold.                           |
| **Even if**         | Condición hipotética poco probable   | Even if it rains, we’ll go to the beach.                    |
| **Whether... or**   | Opción condicional                   | Whether you like it or not, you have to attend the meeting. |

## Conjunciones Comunes en Oraciones Condicionales

Las siguientes conjunciones son las más comunes al formar oraciones condicionales:

### If (si)

La conjunción "if" es la más común en oraciones condicionales y se utiliza para indicar una condición.

Ejemplo:

- "If it rains, we will stay home."
- (Si llueve, nos quedaremos en casa.)

### Unless (a menos que)

"Unless" expresa una condición negativa, es decir, que algo solo sucederá si no ocurre otra cosa.

Ejemplo:

- "We won’t go unless you come with us."
- (No iremos a menos que vengas con nosotros.)

### Provided (that) / Providing (that) (siempre que / con tal de que)

Estas conjunciones indican que una acción se realizará solo si se cumple una condición específica.

Ejemplo:

- "You can borrow my car provided that you return it by tomorrow."
- (Puedes tomar prestado mi coche siempre que lo devuelvas mañana.)

### As long as / So long as (siempre que / mientras)

Estas conjunciones expresan una condición, pero con un sentido de duración o límite temporal.

Ejemplo:

- "You can stay here as long as you don’t make noise."
- (Puedes quedarte aquí mientras no hagas ruido.)

### In case (en caso de que)

"In case" se utiliza para indicar una precaución o medida preventiva frente a una posible situación futura.

Ejemplo:

- "Take an umbrella in case it rains."
- (Lleva un paraguas en caso de que llueva.)

### Even if (incluso si / aunque)

"Even if" introduce una condición que puede ser hipotética o poco probable, enfatizando que el resultado sucederá de todas formas.

Ejemplo:

- "Even if you apologize, I won’t forgive you."
- (Aunque te disculpes, no te perdonaré.)

### Whether... or (ya sea que... o)

Esta conjunción introduce una opción condicional, mostrando que el resultado será el mismo en ambos casos.

Ejemplo:

- "Whether you like it or not, you have to do your homework."
- (Te guste o no, tienes que hacer tu tarea.)

## Tipos de Oraciones Condicionales y su Uso con Conjunciones

### Condicional Tipo 0 (Cero Condicional)

Se utiliza para expresar hechos generales o verdades universales que siempre son verdaderas.

> If + presente simple → presente simple.

Ejemplo:

- "If you heat water to 100°C, it boils."
- (Si calientas el agua a 100°C, hierve.)

### Condicional Tipo 1 (Primer Condicional)

Se utiliza para hablar de situaciones futuras posibles o probables.

> If + presente simple → futuro simple (will).

Ejemplo:

- "If you study hard, you will pass the exam."
- (Si estudias mucho, aprobarás el examen.)

### Condicional Tipo 2 (Segundo Condicional)

Se utiliza para hablar de situaciones hipotéticas o improbables en el presente o futuro.

> If + pasado simple → condicional simple (would).

Ejemplo:

- "If I won the lottery, I would buy a house."
- (Si ganara la lotería, compraría una casa.)

### Condicional Tipo 3 (Tercer Condicional)

Se utiliza para hablar de situaciones hipotéticas en el pasado, que no ocurrieron.

> If + pasado perfecto → condicional perfecto (would have + participio).

Ejemplo:

- "If I had studied harder, I would have passed the exam."
- (Si hubiera estudiado más, habría aprobado el examen.)
