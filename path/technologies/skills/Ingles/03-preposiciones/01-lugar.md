## Preposiciones de Lugar

Las preposiciones de lugar se usan para indicar la posición o el lugar de personas, objetos o lugares en relación con otros. Estas preposiciones son esenciales para describir dónde se encuentra algo o alguien.

## Lista de preposiciones de lugar comunes

| Preposición | Traducción al español  | Ejemplos en inglés                                  | Traducción al español                             |
| ----------- | ---------------------- | --------------------------------------------------- | ------------------------------------------------- |
| In          | En / Dentro de         | The keys are **in** the drawer.                     | Las llaves están **en** el cajón.                 |
| On          | Sobre / Encima de      | The book is **on** the table.                       | El libro está **sobre** la mesa.                  |
| At          | En / Junto a           | I’ll meet you **at** the park.                      | Te veré **en** el parque.                         |
| Under       | Debajo de              | The cat is **under** the bed.                       | El gato está **debajo de** la cama.               |
| Next to     | Al lado de             | The school is **next to** the library.              | La escuela está **al lado de** la biblioteca.     |
| Between     | Entre                  | The pharmacy is **between** the bank and the store. | La farmacia está **entre** el banco y la tienda.  |
| Behind      | Detrás de              | The car is **behind** the house.                    | El coche está **detrás de** la casa.              |
| In front of | Delante de             | The tree is **in front of** the building.           | El árbol está **delante de** el edificio.         |
| Above       | Encima de / Por encima | The picture is **above** the sofa.                  | El cuadro está **encima de**/por encima del sofá. |
| Below       | Debajo de / Por debajo | The lamp is **below** the shelf.                    | La lámpara está **debajo de** la estantería.      |
| Opposite    | Enfrente de            | The restaurant is **opposite** the cinema.          | El restaurante está **enfrente de** el cine.      |
| Near        | Cerca de               | The hospital is **near** my house.                  | El hospital está **cerca de** mi casa.            |
| Far from    | Lejos de               | The airport is **far from** the city.               | El aeropuerto está **lejos de** la ciudad.        |
| Over        | Encima (sin contacto)  | The plane is flying **over** the mountains.         | El avión está volando **encima de** las montañas. |
| Inside      | Dentro de              | The dog is **inside** the house.                    | El perro está **dentro de** la casa.              |
| Outside     | Fuera de               | They are waiting **outside** the building.          | Están esperando **fuera de** del edificio.        |

## Uso de preposiciones de lugar con ejemplos

### In (En, Dentro de)

Se usa cuando algo o alguien está dentro de un espacio o área cerrada.

| Ejemplo en inglés                       | Traducción al español                     |
| --------------------------------------- | ----------------------------------------- |
| The kids are playing **in** the garden. | Los niños están jugando **en** el jardín. |
| There is milk **in** the fridge.        | Hay leche **en** el refrigerador.         |

### On (Sobre, Encima de)

Se usa para hablar de algo que está sobre una superficie.

| Ejemplo en inglés                    | Traducción al español               |
| ------------------------------------ | ----------------------------------- |
| The phone is **on** the table.       | El teléfono está **sobre** la mesa. |
| There is a painting **on** the wall. | Hay un cuadro **en** la pared.      |

### At (En, Junto a)

Se usa para ubicaciones específicas o puntos concretos.

| Ejemplo en inglés                 | Traducción al español                 |
| --------------------------------- | ------------------------------------- |
| I’ll see you **at** the bus stop. | Te veré **en** la parada de autobús.  |
| She is waiting **at** the door.   | Ella está esperando **en** la puerta. |

### Under (Debajo de)

Se usa para indicar que algo está directamente debajo de otra cosa.

| Ejemplo en inglés                      | Traducción al español                         |
| -------------------------------------- | --------------------------------------------- |
| The shoes are **under** the bed.       | Los zapatos están **debajo de** la cama.      |
| The cat is hiding **under** the table. | El gato está escondido **debajo de** la mesa. |

### Behind (Detrás de)

Se usa para indicar que algo está detrás de otra cosa.

| Ejemplo en inglés                  | Traducción al español                      |
| ---------------------------------- | ------------------------------------------ |
| The bike is **behind** the garage. | La bicicleta está **detrás de** el garaje. |
| The tree is **behind** the house.  | El árbol está **detrás de** la casa.       |

### In front of (Delante de)

Se usa para describir algo que está delante de otra cosa.

| Ejemplo en inglés                               | Traducción al español                              |
| ----------------------------------------------- | -------------------------------------------------- |
| The car is parked **in front of** the building. | El coche está aparcado **delante de** el edificio. |
| The bus is **in front of** the school.          | El autobús está **delante de** la escuela.         |

## Diferencias entre "In", "On" y "At"

Estas tres preposiciones se confunden a menudo.

- In: Se usa para lugares grandes o cerrados (habitaciones, ciudades, países).

  - Ejemplo: In the room, in New York, in the garden.

- On: Se usa para superficies o medios de transporte.

  - Ejemplo: On the table, on the bus, on the wall.

- At: Se usa para ubicaciones específicas o direcciones.
  - Ejemplo: At the door, at the station, at 123 Main Street.
