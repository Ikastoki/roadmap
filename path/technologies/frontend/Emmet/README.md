# Emmet

Emmet es un conjunto de abreviaturas o atajos que se utilizan en editores de texto y entornos de desarrollo web para agilizar la escritura de código [HTML](01-HTML.md) y [CSS](./02-CSS.md). Originalmente conocido como "Zen Coding," Emmet se ha convertido en una herramienta muy popular para aumentar la productividad de los desarrolladores web al permitirles escribir código de manera más rápida y eficiente.

En resumen: **Sirve para escribir más rápido mediante atajos.**
