## Módulo os (Sistema Operativo)

El módulo os es un módulo nativo de Node.js que te proporciona información y herramientas para interactuar con el sistema operativo en el que se está ejecutando tu aplicación. Es muy útil para tareas de configuración, registro y para crear aplicaciones que se comporten de manera diferente según el entorno.

Para usarlo, lo importas de la siguiente manera:

```javascript
const os = require("node:os");
```

## Métodos más comunes

### os.platform()

Devuelve una cadena de texto que identifica la plataforma del sistema operativo. Los valores comunes son 'darwin' (macOS), 'win32' (Windows) y 'linux'. Esto es útil si necesitas ejecutar código específico para un sistema operativo.

```javascript
console.log(os.platform()); // Salida: 'darwin' o 'win32' o 'linux'
```

### os.arch()

Devuelve la arquitectura del CPU del sistema operativo, como 'x64' o 'arm64'.

```javascript
console.log(os.arch()); // Salida: 'x64'
```

### os.cpus()

Devuelve un array de objetos que contienen información sobre cada núcleo de CPU disponible. Puedes usarlo para saber cuántos núcleos tiene el sistema y distribuir la carga de trabajo.

```javascript
const cpus = os.cpus();
console.log(`El sistema tiene ${cpus.length} núcleos de CPU.`);
console.log("Información del primer núcleo:", cpus[0]);
```

### os.freemem() & os.totalmem()

`os.freemem()`: Devuelve la cantidad de memoria libre del sistema en bytes.

`os.totalmem()`: Devuelve la cantidad total de memoria del sistema en bytes.

```javascript
const memoriaLibre = os.freemem();
const memoriaTotal = os.totalmem();
console.log(`Memoria libre: ${memoriaLibre / 1024 / 1024} MB`);
console.log(`Memoria total: ${memoriaTotal / 1024 / 1024} MB`);
```

Estos métodos son útiles para monitorear el rendimiento de tu servidor.

### os.homedir()

Devuelve la ruta del directorio principal del usuario actual. Esto es útil para, por ejemplo, almacenar archivos de configuración en el directorio del usuario.

```javascript
console.log(os.homedir()); // Salida en macOS: '/Users/usuario'
```

### os.uptime()

Devuelve el tiempo de actividad del sistema operativo en segundos.

```javascript
console.log(`El sistema lleva activo ${os.uptime()} segundos.`);
```

El módulo `os` te proporciona una visión interna del sistema en el que se ejecuta tu aplicación, lo que te permite tomar decisiones inteligentes y crear código más robusto y adaptativo.
