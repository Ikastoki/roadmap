## Módulo fs (File System)

El módulo fs es uno de los módulos nativos más importantes de Node.js. Te permite interactuar directamente con el sistema de archivos del servidor. Con este módulo, puedes leer, escribir, actualizar, eliminar y gestionar archivos y directorios de forma programática.

Para usarlo, lo importas de la siguiente manera:

```javascript
const fs = require("node:fs");
```

## Asíncronia

El módulo fs tiene dos versiones para cada operación:

- Asíncrona (no bloqueante): Es la forma recomendada. Toma una función callback que se ejecuta cuando la operación termina, permitiendo que el hilo principal siga funcionando.

- Síncrona (bloqueante): Bloquea el hilo de ejecución hasta que la operación se completa. Solo es útil para scripts simples o en la inicialización de la aplicación, donde un bloqueo breve no es un problema.

## Operaciones más comunes

### Lectura de archivos

`fs.readFile(ruta, [opciones], callback)`: Lee el contenido de un archivo. Cuando la lectura termina, la función callback se ejecuta con el error (si lo hay) y los datos del archivo.

```javascript
fs.readFile("miarchivo.txt", "utf8", (err, data) => {
  if (err) {
    console.error("Error al leer el archivo:", err);
    return;
  }
  console.log("Contenido del archivo:", data);
});
```

El parámetro `'utf8'` es importante para que los datos se interpreten como una cadena de texto y no como un `buffer` de bytes.

### Escritura de archivos

`fs.writeFile(ruta, datos, [opciones], callback)`: Escribe datos en un archivo. Si el archivo no existe, lo crea. Si ya existe, su contenido se sobrescribe por completo.

```javascript
const contenido = "Hola, mundo desde Node.js.";
fs.writeFile("nuevo-archivo.txt", contenido, (err) => {
  if (err) {
    console.error("Error al escribir el archivo:", err);
    return;
  }
  console.log("Archivo creado y escrito con éxito.");
});
```

### Adición de contenido a un archivo

`fs.appendFile(ruta, datos, [opciones], callback)`: Añade datos al final de un archivo sin sobrescribir su contenido existente

```javascript
const nuevoContenido = "\n¡Este es un nuevo texto!";
fs.appendFile("nuevo-archivo.txt", nuevoContenido, (err) => {
  if (err) {
    console.error("Error al añadir contenido:", err);
    return;
  }
  console.log("Contenido añadido al archivo.");
});
```

## Otras operaciones comunes

- `fs.unlink(ruta, callback)`: Elimina un archivo.

- `fs.rename(rutaAntigua, rutaNueva, callback)`: Renombra o mueve un archivo.

- `fs.mkdir(ruta, [opciones], callback)`: Crea un nuevo directorio.

- `fs.rmdir(ruta, callback)`: Elimina un directorio.

El módulo `fs` es el pilar para cualquier aplicación que necesite persistir datos en el sistema de archivos del servidor. Es la forma en que Node.js interactúa con su entorno de manera fundamental.
