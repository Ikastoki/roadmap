# Licencias y modelos de distribución

Las licencias de software definen los términos bajo los cuales un programa puede ser utilizado, modificado y distribuido. Comprender las licencias es fundamental tanto para los desarrolladores que crean software como para los usuarios que lo utilizan, ya que determinan los derechos y obligaciones legales de ambas partes. Una licencia inadecuada puede generar problemas legales costosos, mientras que una licencia bien elegida puede maximizar la adopción del software y proteger a sus creadores.

## Licencias

Una licencia de software es un contrato legal entre el titular de los derechos de autor (*copyright*) y el usuario, que especifica qué se permite hacer con el software. Sin una licencia explícita, el software está protegido por las leyes de derechos de autor por defecto, lo que significa que nadie tiene derecho a usarlo, copiarlo o distribuirlo sin permiso explícito del titular.

Los tipos principales de licencias se pueden clasificar en dos grandes categorías:

**Licencias propietarias:** el titular de los derechos conserva todos los derechos sobre el software. El usuario adquiere una licencia de uso que le permite ejecutar el software bajo condiciones específicas, pero no puede modificarlo, redistribuirlo ni acceder al código fuente. Ejemplos: licencias de Microsoft Windows, Adobe Photoshop, Oracle Database.

**Licencias de código abierto (*open source*):** permiten al usuario usar, modificar y redistribuir el software, sujeto a las condiciones específicas de cada licencia. El código fuente está disponible para que cualquiera pueda inspeccionarlo, mejorarlo y crear versiones derivadas.

## Modelos de distribución

**Software propietario:** se distribuye como binario compilado sin acceso al código fuente. El usuario paga por una licencia de uso y depende del fabricante para actualizaciones, correcciones y soporte. Este modelo maximiza el control del fabricante sobre el producto pero limita la flexibilidad del usuario.

**Software libre (*free software*):** según la definición de la Free Software Foundation, el software libre garantiza al usuario cuatro libertades fundamentales: ejecutar el programa con cualquier propósito, estudiar cómo funciona y modificarlo (requiere acceso al código fuente), redistribuir copias, y distribuir versiones modificadas.

**Software de código abierto (*open source*):** similar al software libre pero con un enfoque más pragmático en los beneficios prácticos de la colaboración abierta: mayor calidad del código (más ojos revisando), innovación más rápida, ausencia de lock-in con proveedores.

**Freeware:** software gratuito que no proporciona acceso al código fuente. El usuario puede usarlo sin pagar pero no puede modificarlo ni redistribuirlo. Ejemplos: Skype, Adobe Acrobat Reader.

**Shareware:** software que se distribuye gratuitamente durante un período de prueba, después del cual se requiere una licencia de pago para seguir usándolo. El período de prueba puede ser temporal (30 días) o funcional (versión limitada).

**Donationware:** software gratuito que solicita donaciones voluntarias para su mantenimiento. El usuario puede usar el software sin pagar, pero se le anima a contribuir económicamente si le resulta útil.

## Tipos de licencias de código abierto

**GPL (*GNU General Public License*):** la licencia de código abierto más utilizada, creada por la Free Software Foundation. La GPL garantiza que el software y todas sus modificaciones permanezcan libres: cualquier trabajador derivado debe distribuirse bajo los mismos términos GPL (*copyleft*). Esto impide que el software GPL se incorpore a software propietario sin liberar el código completo.

**MIT:** una de las licencias más permisivas. Permite usar, modificar y redistribuir el software con prácticamente ninguna restricción, incluyendo la incorporación a software propietario. Solo requiere incluir una copia del aviso de copyright y la licencia original.

**Apache 2.0:** similar a MIT pero con protección adicional contra patentes: los contribuyentes otorgan una licencia de uso de patentes relacionadas con el software. Es preferida por empresas que desean contribuir a proyectos de código abierto sin riesgo de litigios por patentes.

**BSD (*Berkeley Software Distribution*):** licencia permisiva similar a MIT, con variantes que añaden restricciones sobre el uso del nombre del producto original en publicidad de versiones derivadas.

> La elección de licencia tiene implicaciones estratégicas a largo plazo. Una empresa que incorpora código GPL a su producto está obligada a liberar el código fuente completo de su producto. Una empresa que incorpora código MIT o Apache puede mantener su propio código propietario. Esta distinción es fundamental para la planificación de desarrollo de software empresarial.

## La ética y legalidad en el uso del software

El uso de software implica obligaciones éticas y legales que van más allá de la mera instalación:

**Derechos de autor (*copyright*):** el creador de un software tiene automáticamente derechos de autor sobre su obra. Usar, copiar o distribuir software sin una licencia que lo permita es una violación del copyright que puede acarrear sanciones legales significativas.

**Piratería de software:** la copia y distribución no autorizada de software propietario es ilegal en la mayoría de jurisdicciones. Las consecuencias pueden incluir multas civiles, daños y perjuicios y, en casos graves, responsabilidad penal.

**Cumplimiento de licencias:** las organizaciones que utilizan software de código abierto deben cumplir con los términos de las licencias aplicables. Esto puede incluir la obligación de distribuir el código fuente de sus modificaciones (GPL), incluir avisos de copyright (MIT/Apache) o documentar los cambios realizados.

**Software libre como cuestión ética:** para la Free Software Foundation y sus seguidores, el software libre es una cuestión de libertad, no de precio. El derecho del usuario a estudiar, modificar y compartir el software que utiliza es considerado un derecho fundamental comparable a la libertad de expresión.
